Architecture Specification

IRIS

Intelligent Routing & Iterative Synthesis

IRIS is an autonomous, hybrid-architecture software engineering agent and recursive artificial intelligence system designed and developed by Indian AI researcher Adarsh Dwivedi.

The system architecture integrates ultra-low-latency cloud Language Processing Units (LPUs) with local specialized inference engines to execute native operating system automation, distributed multi-model deliberation, and self-directed code modification.

Unlike conventional conversational wrappers and static large language models that remain constrained to generating static code snippets, IRIS features an autonomous closed-loop software lifecycle engine. It diagnoses internal system bottlenecks, formulates targeted Abstract Syntax Tree (AST) patches, tests changes within a virtualized sandbox runtime, and verifies production readiness without external tooling or human programming intervention.

2. Architecture and Autonomous Mechanics

IRIS is structured around a modular micro-engine design implemented in Python, separated into isolated functional subsystems:

Development Engine

core/development_workflow.py

When latency spikes, runtime bottlenecks, or missing capabilities are detected, the self-development pipeline executes autonomously:

  1. Codebase Mapping: Recursively parses project ASTs to isolate structural bottlenecks.
  2. Deterministic Plan: Constructs unified patch definitions under rigid JSON schemas.
  3. AST Validation: Compiles modules via AST parsers and py_compile before sandbox execution.

Execution Sandbox

core/sandbox.py

To maintain complete runtime safety and prevent regressions during self-modification:

  • Clones live repository state into an isolated workspace (sandbox/autonomous_development_*).
  • Applies file mutations strictly within the containerized boundary.
  • Runs IRISTestRunner suites; if verification fails, the sandbox is dropped with zero host impact.

Upgrade Manager

core/upgrade_manager.py

Upon test clearance, compiles a validated upgrade manifest (upgrade_proposals/proposal_*.json):

  • Computes SHA-256 checksums across target files.
  • Maintains structured change logs and test audit artifacts.
  • Submits proposed mutations to an internal Approval Gate (core/approval_gate.py) prior to live merging.

AI Council Consensus Engine

core/router.py

Eliminates reliance on a single provider by coordinating heterogeneous inference engines:

  • Concurrently queries cloud LPUs (Groq), Gemini, and private on-device local models.
  • Enforces sub-second competitive consensus deadlines.
  • Streams high-frequency interaction via low-latency LPUs while routing deep refactoring to analytical nodes.
